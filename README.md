# 🌤️ Weather Dashboard
A responsive weather dashboard that allows users to search for the current weather conditions of any city.

## 🚀 Live Demo
https://whetherdashboard.vercel.app

## ✨ Features
- 🔍 Search weather by city name
- 🌡️ Displays current temperature
- 💧 Shows humidity
- 💨 Shows wind speed
- 🌡️ Displays feels-like temperature
- ☁️ Displays current weather condition
- 📱 Responsive design
- 🔐 API key securely stored using Vercel Environment Variables

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Vercel Serverless Functions
- GitHub

## ⚙️ How It Works
1. Enter the name of a city.
2. Click the **Search** button.
3. The application sends the city name to the backend API.
4. The serverless function securely uses the OpenWeatherMap API key.
5. Weather information is returned and displayed on the dashboard.

## 🔐 Security
The OpenWeatherMap API key is stored as an environment variable in Vercel and is not included in the GitHub repository.
